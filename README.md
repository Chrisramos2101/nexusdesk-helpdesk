# NexusDesk

Professional Help Desk & IT Ticket Management System built with Flask, PostgreSQL, Docker, and AWS deployment architecture.

## Features

### Authentication & Security
- Secure Login System
- Password Hashing
- MFA Email Verification
- Password Reset Tokens
- CSRF Protection
- Role-Based Access Control
- Session Security
- Failed Login Tracking
- Security Cleanup Tools

### Ticket Management
- Create Tickets
- Assign Technicians
- Ticket Categories
- Priority Levels
- SLA Tracking
- Ticket Notes
- Attachments
- Ticket Search & Filtering
- Resolution Tracking

### User Management
- Admin Portal
- Employee Portal
- Create Users
- Edit Users
- Delete Users
- Department Management

### Analytics & Monitoring
- Statistics Dashboard
- System Dashboard
- Audit Logging
- Email Event Tracking
- MFA Monitoring
- Health Check Endpoint
- Application Monitoring

### Infrastructure
- PostgreSQL
- Docker
- CI/CD Pipeline
- AWS Deployment Ready
- Production Environment Configuration

```bash
cd helpdesk-system

docker compose up --build
```

Open:

```
http://localhost:5000
```
